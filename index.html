Getting Started

Board the Ark in minutes

Install the APK, pick a distro, and launch your first desktop.

1

Install the APK

Grab the latest release from GitHub, install it, and grant the requested permissions. Requires Android 10 (API 29)+.

2

Pick your distro & update

Select a Linux distribution, wait for install, then restart into the shell. First things first:

apt update && apt upgrade -y
3

Install a desktop environment

Choose a GUI such as XFCE4, then pick your display backend (X11 or Wayland).

4

Launch the desktop

Start your session from the terminal or a script button. For XFCE4 on X11:

export DISPLAY=:0
 dbus-launch --exit-with-session xfce4-session &
